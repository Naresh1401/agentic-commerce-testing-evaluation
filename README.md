# Agentic Testing and Evaluation Framework

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Golden dataset, API tests, contract tests, MCP schema tests, prompt injection tests, RBAC tests, and RAG evaluation notes.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
